Apuntes personales de estudios de interés, además de asignaturas cursadas en la Facultad de Ciencias Físicas y Matemáticas de la Universidad de Chile.

# Visualización
Para la visualización de los apuntes, es recomendado utilizar Obsidian. Con ello, se puede observar la conectividad entre contenidos.

# Recomendaciones
Recomiendo el uso de las extensiones:
- Latex Suite: Permite escribir fórmulas matemáticas y bloques de código rápidamente a través de snippets de texto que se reemplazan por el formato Markdown a utilizar.
- Git: Para usar control de versión en los documentos.
- Execute Code: Permite ejecutar bloques de código dentro de Obsidian.
- Code Styler: Formato de los bloques de código
- Tabout: Navegación más sencilla con teclado.
